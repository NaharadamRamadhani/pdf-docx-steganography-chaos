# PDF & DOCX Document Steganography using Chaos MS-Tent Map & Fisher-Yates Shuffle

A desktop-based steganography application designed to embed and extract secret messages or data within digital documents (`.pdf` and `.docx`). This project implements the **Chaos MS-Tent Map** and **Fisher-Yates Shuffle Algorithm** to randomize insertion points, significantly enhancing encryption security while maintaining document imperceptibility.

---

## 📌 Key Features

- **Data Embedding & Extraction:** Hide and retrieve secret messages within `.pdf` and `.docx` files securely.
- **Fisher-Yates Shuffle:** Randomizes insertion indices to ensure non-linear data placement.
- **Chaos MS-Tent Map:** Leverages chaotic mapping for high-degree encryption sensitive to initial key parameters.
- **Security & Imperceptibility Testing:**
  - **Imperceptibility Evaluation:** Assesses visual distortion to ensure modified documents remain visually identical to the original.
  - **Security Evaluation:** Analyzes key space size and resistance against unauthorized extraction attempts.
